# Ticket format (Atmira)

Write one ticket for the problem the user describes, with exactly this layout and nothing else:

```
🎫 ATM-NEW · {title in the imperative, max 50 characters}
Priority: {high, medium or low}
Why: {one sentence}
Done when: {one sentence a tester can check}
```
